# Python Contact Management Application

A lightweight, terminal-based contact management system built with Python. Designed for clean data handling, efficient searching, and structured local storage.

## Features
* **Add Contacts:** Store names, phone numbers, and details with formatted validation.
* **Search & Filter:** Instantly look up contact records by name.
* **View All:** List all stored contacts cleanly in the terminal.
* **Persistent Structure:** Built with clean modular functions for easy scaling.

## Tech Stack
* **Language:** Python 3
